Library Management System

A Windows desktop application for managing a library, built with C# and Windows Forms in Visual Studio. This is the entry point of the system, where users sign in or create an account before using the app.

Login screen: a clean form with username, password and confirm password fields, a "Show Password" checkbox so users can check what they typed, a Sign In button and a Create Account button that opens a separate registration form.

Design: a borderless custom window with a navy and green colour scheme, a library logo, a "Welcome, Please Login!" message and a vertical "LOGIN FORM" banner along the side.

What I practised: designing Windows Forms layouts, working with multiple forms (login, registration and main form) and building a simple, user-friendly interface.
